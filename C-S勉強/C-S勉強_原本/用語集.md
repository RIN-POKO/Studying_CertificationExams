# 用語集（Claude Sales）

Claude Sales で押さえておくべき製品・商談・セキュリティ・導入推進の重要用語を整理しています。暗記テスト機能（HTML 版の「暗記マスク」）と組み合わせて確認してください。

## 1. 製品・提供形態

| 用語 | 意味 | 混同・注意ポイント |
| --- | --- | --- |
| **Claude for Work** | 法人向け SaaS プラン（Team / Enterprise）の総称 | 個人向け（Free / Pro）とは契約条件とデータ保護が異なる |
| **Claude Enterprise** | 大企業向けの最上位 SaaS プラン | SSO、SCIM、Audit Logs、Compliance API、Custom Retention を備える |
| **Shadow AI** | 社員が会社管理外の個人向け AI へ業務データを入力している状態 | 禁止するだけでなく、安全な法人環境（Enterprise）へ移行させるのが営業の役割 |
| **Projects / Artifacts** | チームで前提資料を共有する場（Projects）と成果物を並べて編集する機能（Artifacts） | 単発チャットとの差別化・日常定着の要になる機能 |
| **Cloud Marketplaces** | AWS Bedrock や Google Cloud Vertex AI 経由で Claude を調達・運用する形態 | 既存クラウドの審査済み環境や EDP 契約枠を活用できる |

## 2. 商談・ヒアリング

| 用語 | 意味 | 混同・注意ポイント |
| --- | --- | --- |
| **Discovery** | 提案前に顧客の課題、数値目標、クラウド環境、決裁構造を聞き出す工程 | デモを見せる前に実施し、提案の焦点を合わせる |
| **Champion** | 顧客社内で導入を推進し、他部門や決裁者との調整を助けてくれる味方 | 技術者だけでなく、現場の業務影響力を持つ人物を見極める |
| **Economic Buyer** | 予算承認と契約の最終決定権を持つ責任者 | 現場担当者と盛り上がっても、Economic Buyer の関心（ROI・リスク）を外すと失注する |
| **Land and Expand** | まず 1〜2 部門で小さく成果を出し（Land）、全社へ広げる（Expand）戦略 | 最初から全社一括を狙うより承認が通りやすい |

## 3. セキュリティ・コンプライアンス

| 用語 | 意味 | 混同・注意ポイント |
| --- | --- | --- |
| **Zero Training by Default** | 商用プランや API の入力データをモデル学習に使わない原則 | 個人プランとの違いを説明する際の最重要ポイント |
| **SOC 2 Type II** | セキュリティ・可用性等の統制が一定期間適切に運用されている第三者監査証明 | 企業のベンダーリスク評価（VRA）で高確率で求められる |
| **HIPAA / BAA** | 米国医療情報保護法への準拠と、事業者責任を定める契約（BAA） | 医療・ヘルスケア・製薬顧客では早期に確認が必要 |
| **DPA** | 個人データの適切な処理条件を定めるデータ処理補遺契約 | GDPR 等の個人情報保護要件への対応根拠になる |
| **Audit Logs / Compliance API** | 組織の利用履歴や会話データをプログラム経由で SIEM 等へ連携できる機能 | CISO の「社員の利用状況を監視したい」という要望への直接解 |
| **Custom Data Retention** | 企業ポリシーに合わせてデータの自動削除期間を設定できる機能 | 「無期限保持は社内規程違反」という反論への切り返しに使う |

## 4. ROI・導入拡大

| 用語 | 意味 | 混同・注意ポイント |
| --- | --- | --- |
| **Baseline / Success Metrics** | 導入前の現状値と、パイロット合格を判定する事前合意目標値 | 導入後に「良かった気がする」で終わらせないために事前設定する |
| **ROI Scorecard** | 導入コストと定量削減効果を対比して示す評価資料 | 経営層への本番予算稟議・更新商談の根拠になる |
| **30-Day Fade** | 導入後 1 か月前後で利用率が急落する企業導入の典型的な失速現象 | ツール配布だけでなく定着支援をセット提案すべき理由 |
| **Role-Based Training** | 職種ごとの実務シナリオに即したハンズオン研修 | 全社一律の一般説明会より実務定着率が高い |
| **Claude Partner Network (CPN)** | Anthropic のパートナー制度（Select / Preferred / Global Premier 等） | 認定資格数と顧客導入実績がパートナーティアに直結する |
