# 直前チェック（Claude Sales）

商談・提案・反論処理・導入拡大の 4 領域について、迷いやすい二択と総合シナリオ問題で最終確認します。

## 商談場面別：二択判断表

| 場面 | 避けるべき判断 | とるべき判断 |
| --- | --- | --- |
| **Shadow AI 対策** | 個人 Pro アカウントの業務利用を容認・放置する | 学習除外・SSO・監査ログが効く Claude Enterprise への統合を提案する |
| **自社アプリ組み込み** | ユーザー数分の SaaS シートを販売しようとする | Anthropic API、または Bedrock / Vertex AI の API 利用を提案する |
| **既存クラウド調達** | 直接契約（1st-party）のみに固執して審査で止まる | 既存の AWS（Bedrock）や Google Cloud（Vertex AI）と EDP 枠の活用を提案する |
| **商談の進め方** | 顧客の課題を聞かずに全機能のデモを一方的に見せる | Discovery で業務課題・データ所在・IT 要件を聞き出してから焦点を絞る |
| **セキュリティ反論** | 「安全ですので大丈夫です」と口頭だけで答える | Zero Training 条項、SOC 2 Type II、DPA / BAA、Audit Logs 等の根拠を示す |
| **監査・SIEM 要件** | ログ監視はできないと諦めるか手作業運用を勧める | Enterprise Audit Logs と Compliance API による SIEM 連携を案内する |
| **保持期間の懸念** | デフォルトの無期限保持しか選べないと説明する | 管理者が Custom Data Retention で自動削除期間を設定できると説明する |
| **初期スコープ** | 最初から全社全部門一括の巨大契約だけを迫る | Land and Expand に沿って 1〜2 部門の First Slice から始める |
| **効果測定** | 導入後に感想を聞いて ROI を判断する | 開始前に Baseline と Success Metrics を合意し ROI Scorecard で証明する |
| **導入後の定着** | ライセンス納品だけで営業・支援を終了する | Champion Network と職種別トレーニングで 30-Day Fade を防ぐ |

## 総合確認問題（シナリオ形式）

### 総合問 1（ポジショニング ＋ セキュリティ反論）

従業員 2,000 名の金融サービス企業から「社内で個人の生成 AI アカウントが使われており情報漏洩が心配だ。全社で統一環境を導入したいが、全社標準は AWS であり、社員の利用ログは既存の SIEM へ取り込みたい。また入力データがモデルの学習に使われない保証も必須」と相談を受けました。営業担当として最も適切な提案の組み合わせはどれですか。

A. 個人向け Pro プランを全員に配布し、パスワードを複雑にするよう通達する  
B. 社員の日常業務向けには SSO・Audit Logs・Compliance API・Zero Training を備えた Claude Enterprise を提案し、自社システム連携や閉域網ワークロードには Amazon Bedrock の併用も選択肢として示す  
C. Free プランのブラウザ利用を推奨し、週 1 回スクリーンショットを提出させる  
D. セキュリティ要件が厳しいため、AI 導入自体を見送るよう助言する

<details>
<summary>解答</summary>

**B**。Shadow AI の解消と SIEM 監査・学習除外の要件には Claude Enterprise が適合し、AWS 標準の自社システム連携や閉域網要件には Amazon Bedrock を組み合わせるのが実務的な最適解です。

</details>

### 総合問 2（Discovery ＋ Land and Expand ＋ ROI）

ある製造業の顧客が「全社で Claude を導入したいが、役員会が投資対効果に懐疑的で予算が通りにくい」と悩んでいます。商談を前進させる提案戦略として最も適切なものはどれですか。

A. 「他社もみんな使っているので大丈夫です」と精神論で説得する  
B. まず効果を測定しやすい 1〜2 部門を Land（着地）対象に選び、導入前の Baseline と達成基準の Success Metrics を定義した ROI Scorecard を作成して、短期パイロットの実績をもとに全社拡大（Expand）を図る  
C. 役員会を通さずに現場の経費で 1 アカウントずつ購入してもらう  
D. 全社予算が下りるまで 2 年間待つ

<details>
<summary>解答</summary>

**B**。懐疑的な決裁者には Land and Expand で初期投資とリスクを抑えつつ、Baseline と ROI Scorecard で定量効果を証明する提案が最も効果的です。

</details>

### 総合問 3（定着支援 ＋ 規制要件）

ヘルスケア関連企業で Claude Enterprise の導入が決まり、HIPAA 対応の BAA も締結しました。しかし営業担当は契約締結と同時に次の新規案件へ移り、顧客社内へのトレーニングや推進体制は一切組まれませんでした。2 か月後に予想される最大のリスクと、本来とるべきだった対策はどれですか。

A. HIPAA の法律が自動的に無効になるため、毎日契約書を再締結すべきだった  
B. 導入初期の関心が薄れて利用率が急落する 30-Day Fade が起きやすいため、部門別 Champion Network の設置と職種別トレーニング（Role-Based Training）を組み込んでおくべきだった  
C. ライセンス費用が自動的に 10 倍になるため、全アカウントを停止すべきだった  
D. 監査ログが消滅するため、紙のノートで記録すべきだった

<details>
<summary>解答</summary>

**B**。契約とコンプライアンス対応が完了しても、現場での使い方支援と推進体制がなければ 30-Day Fade が起きて更新・拡大に失敗します。Champion Network と職種別トレーニングの伴走が不可欠です。

</details>
